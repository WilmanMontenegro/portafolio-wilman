01 · Base

IA generativa y modelo

IA generativa

Una IA que crea cosas nuevas: texto, imágenes, audio o video. No solo busca lo que ya existe.

Modelo

El cerebro entrenado que hace el trabajo. Hay modelos livianos (rápidos/baratos) y fuertes (más caros).

Hoy usamos sobre todo modelos de lenguaje (LLM). En Cursor eliges cuál modelo te conviene.

02 · LLM

Large Language Model (LLM)

Modelo de lenguaje grande · No es una base de datos
En simple

Una IA que entiende y genera texto.

Cómo funciona

No “busca y encuentra”. Predice la siguiente palabra.

patrones + tu pregunta
→ siguiente palabra
Puede sonar bien y estar mal.

En tu día a día

¿En qué puedes usar la IA?

Textos y correos

Escribir informes, propuestas, mails a clientes, actas y resúmenes sin empezar en blanco

Campañas y creatividades

Ideas de publicidad, copys, imágenes, videos cortos y presentaciones para vender más

Datos y números

Entender tablas, ventas, gastos y variaciones; borradores de reportes listos para revisar

Automatizar

Ahorrar tiempo en tareas repetidas: clasificar, ordenar, responder lo frecuente y organizar el trabajo

La IA acelera tu trabajo. Tú decides y verificas.

03 · Prompts

Prompt = lo que le pides a la IA

Es lo que escribes en el chat. Un buen prompt tiene 4 partes:
01 Rol

Quién quieres que sea

02 Tarea

Qué quieres que haga

03 Contexto

Tu negocio, tono y límites

04 Formato

Largo, estructura y cómo debe cerrar

Sin estas 4 partes, la IA improvisa y pierdes tiempo. Mejor pídeselo con tu contexto real.

Ejemplo real · negocio

Malo vs bueno

Prompt malo

Hazme un informe de ventas.

Vago. Sin rol, datos, tono ni formato. Respuesta genérica.

Prompt bueno

Eres analista financiero de una PYME en Colombia. Con estos datos de ventas del mes [pega tabla], arma un resumen ejecutivo de máximo 200 palabras. Incluye: 3 hallazgos, 2 riesgos y 1 recomendación. Tono profesional. No inventes cifras que no estén en los datos.

04 · Token y ahorrar

Token = pedacito de texto

Se cobra por pedacitos, no por “palabras” · Entrada barata · Salida cara
Regla práctica

1 token ≈ 3–4 caracteres

130–150 tokens ≈ 100 palabras

Mail corto ≈ 40-80 · informe ≈ 200-400

Por qué te importa

Cada mensaje reenvía el chat: lo anterior + lo nuevo + la respuesta.

No “recuerda” gratis. Chat largo = más gasto. Sé claro y corto.

Entrada

Lo que tú escribes.
Más barato.

Salida

Lo que responde la IA.
3× a 6× más caro.

Pide formato corto. No pegues chats viejos.

05 · Ventana de contexto

Contexto = lo que puede leer de una vez

Tu pregunta + el chat anterior + archivos. Tiene tope. No es memoria eterna.
Chat nuevo por tarea

Un chat para el informe. Otro para el correo. No mezcles temas.

Solo lo necesario

Resumen, tono y datos clave. No pegues todo el Drive “por si acaso”.

Si el chat se alarga

Resume lo importante, o abre un chat nuevo.

Archivos con criterio

Sube el PDF o documento correcto. Menos archivos = menos ruido.

Buen contexto = lo justo para la tarea. No es “más = mejor”.

06 · Modelo correcto

Elige el modelo adecuado

En Cursor (y en otras IAs) hay varios modelos. No uses el más Pro para todo.
Barato · rápido

Resumir, clasificar, borradores simples

→
Fuerte · caro

Estrategia y decisiones difíciles

Barato primero. Caro solo si hace falta. Eso es tu retorno: menos gasto y más tiempo.

07 · Riesgos

Alucinaciones y riesgos

Alucinaciones

Inventa cosas que suenan verdad.

Sesgos

Puede repetir prejuicios.

Privacidad

No pegues datos sensibles (contraseñas, clientes, docs privados).

Prompt de internet: léelo. Si pide datos o “ignora reglas”, no lo uses.

La IA propone. Tú verificas, sobre todo las cifras.

08 · Cursor

¿Qué es Cursor?

Un editor con IA: escribes, pides y revisas en el mismo lugar.
Ve tu trabajo

Lee archivos y carpetas. No empiezas de cero en cada chat.

Todo junto

Documento + IA + cambios en una pantalla.

Eliges modelo

Rápido o potente según la tarea (lo que vimos hoy).

Sé realista

Al inicio es un poquito más complicado: nació pensado para programadores. Cuando lo dominas, vuelas con él.

Para llevar

Recuerda esto

→La IA predice texto. Puede sonar bien y estar mal (alucinación). Tú verificas.
→Prompt = rol + tarea + contexto + formato. Cuanto más claro, mejor respuesta.
→Token = pedacito de texto (y gasto). Contexto = lo que el modelo puede leer de una vez.
→No uses el modelo más potente para todo. Empieza simple; sube solo si hace falta.
→No pegues datos sensibles (clientes, contraseñas, documentos privados). Revisa siempre las cifras.

Cierre

La IA potencia tu trabajo.
No te reemplaza.
